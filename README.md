# Car App Store (شبيه AAAD)

1. افتح المجلد في Android Studio (Hedgehog أو أحدث) واتركه يعمل Gradle sync.
2. ارفع catalog.json (بصيغة catalog.example.json) على GitHub أو أي استضافة،
   وغيّر CATALOG_URL داخل Catalog.kt.
3. شغّل التطبيق على التلفون. أول مرة يطلب السماح بتثبيت التطبيقات من هذا المصدر.
4. من زر "إعدادات Android Auto": اضغط 10 مرات على "الإصدار" لتفعيل وضع المطور،
   ثم من قائمة النقاط الثلاث > Developer settings فعّل "Unknown sources".
5. ثبّت التطبيقات من الكتالوج، وستظهر في شاشة السيارة عند اتصال Android Auto.

ملاحظة: قفل الفيديو أثناء حركة السيارة يفرضه نظام السيارة وليس التطبيق.

## اللانچر (Car Launcher)
- أيقونة منفصلة باسم "Car Launcher" (أو زر "اللانچر" داخل التطبيق).
- يعرض كل تطبيقات التلفون بأيقونات كبيرة مع بحث.
- إذا كانت هناك شاشة خارجية متصلة (DeX أو Miracast أو كابل) يظهر مفتاح "الشاشة الخارجية"
  ويشغّل التطبيق عليها مباشرة. التشغيل على شاشة خارجية يعتمد على دعم الجهاز (Samsung DeX يدعمه).
- الاستخدام المقصود: والسيارة واقفة، أو على شاشة المقعد الخلفي للأولاد.

## الحصول على ملف APK بدون Android Studio
1. أنشئ مستودع GitHub جديد وارفع محتويات هذا المجلد (بما فيه .github).
2. افتح تبويب Actions > Build APK > Run workflow.
3. بعد دقائق نزّل CarAppStore-apk من قسم Artifacts، وفيه app-debug.apk.
